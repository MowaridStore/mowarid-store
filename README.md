# متجر مورد — قالب مجاني قابل للتخصيص

متجر للدفع عند الاستلام، مرتبط بـ Mowarid، مع لوحة إدارة عربية وفرنسية. كل متدرب ينشر نسخته في حسابه ويستخدم بيانات مورد والبكسلات الخاصة به. تخصيص الاسم والألوان والمحتوى والمنتجات والأسعار من لوحة الإدارة دون تعديل الكود.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/MowaridStore/mowarid-store)

## تثبيت متجرك

1. جهّز حسابَي GitHub وCloudflare، وفعّل R2 في Cloudflare. قد يُطلب إدخال وسيلة دفع لتفعيل R2؛ الاستخدام يخضع للحصص وأسعار Cloudflare.
2. اضغط **Deploy to Cloudflare**. اختر اسمًا لمتجرك وحسابك ومستودع نسختك. عند طلب `SETUP_TOKEN` اختر عبارة تثبيت خاصة من 24 حرفًا على الأقل واحفظها. هذا ليس مفتاح مورد أو كلمة مرور حسابك.
3. بعد نجاح النشر افتح عنوان الموقع متبوعًا بـ `/admin`، وأدخل عبارة التثبيت.
4. أنشئ حساب المالك ببريدك وكلمة مرور خاصة. الشاشة ترشدك إلى إنشاء **Turnstile** مجاني في Cloudflare لنطاق متجرك، بالنمط **Invisible**؛ أدخل مفتاح الموقع والمفتاح السري في نموذج التثبيت وأكمل التحقق.
5. نزّل ملف الاسترداد واحفظه في مكان خاص. يتضمن رموز استرداد الحساب ومفتاح استعادة النسخ الاحتياطية. لا ترفعه إلى GitHub ولا تشاركه.
6. من لوحة الإدارة، أضف مفتاح مورد الخاص بك، ثم زامن المنتجات والمدن. خصص المتجر والتواصل والشحن، وأضف معرّفات البكسلات ورمز CAPI عند الحاجة.

التثبيت ينشئ D1 للبيانات، وحاويتَي R2 خاصتين للصور والنسخ الاحتياطية، ومفاتيح تشفير مستقلة، وخدمات خاصة للدخول والمهام الخلفية. لا تُضاف منتجات أو حسابات تجريبية إلى النسخة المنشورة.

## الأسعار وعروض الكمية

السعر العادي هو سعر المنتج للزبون دون التوصيل. يمكنك إضافة تخفيض مؤقت، وعروض كمية، وتوصيل مجاني للمنتج أو عند بلوغ حد السلة.

مثال: سعر المنتج 300 درهم؛ الكمية 2 بسعر 250 لكل منتج (الإجمالي 500)؛ الكمية 3 بسعر 230 (الإجمالي 690)؛ ومن الكمية 4 سعر كل منتج 220. عند تغيير العدد تتغير الأسعار تلقائيًا في صفحة المنتج والسلة وصفحة الطلب. تُطبَّق الكميات المحددة على عددها بالضبط، والكميات الأكبر تستخدم السعر الذي تختاره لها. الكميات غير المحددة الأقل من ذلك تستخدم السعر الحالي للمنتج.

تظهر معاينة الربح والحد الأدنى الآمن في الإدارة. يتحقق السيرفر من أن ما يدفعه الزبون يغطي تكلفة منتجات مورد وأعلى تكلفة توصيل رسمية متاحة. انتهاء العروض يعتمد على ساعة السيرفر؛ إذا تغير السعر قبل تأكيد الطلب تُطلب مراجعة الإجمالي. أسعار الطلبات السابقة محفوظة.

## التحديثات والبيانات

كل متجر له مستودعه وموارده الخاصة. تحديث مستودع نسختك يُطلق Workers Builds إذا كان الربط مفعّلًا. لا ينتقل تحديث المستودع الأصلي إلى نسختك تلقائيًا، ولا يوجد إشعار تحديث داخل المتجر حاليًا.

احتفظ باسم Worker وموارد D1 وR2 والأسرار الأصلية. أمر النشر يطبق التحديثات الناقصة لقاعدة البيانات ويحافظ على البيانات؛ لا ينشئ بيانات تجريبية ولا يدور مفاتيح متجر موجود تلقائيًا. احتفظ بنسخة احتياطية قبل تحديثاتك، وراجع [دليل النشر والتحديث](docs/DEPLOYMENT.md).

## التشغيل المحلي للمطور

يتطلب Node.js 22.12 أو أحدث.

```sh
npm ci
npm run setup:local
npm run db:migrate
npm run db:demo
npm run dev
```

افتح `http://localhost:8788/admin#setup=<SETUP_TOKEN>` بالقيمة الخاصة من `.dev.vars`. منتجات `fixtures/demo.sql` خيالية للاختبار المحلي فقط. لا تنفذ `db:demo` على الإنتاج. بيئتا التطوير والنشر تعملان على Workers.

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run security:source
```

للنشر اليدوي بعد ربط حساب Cloudflare: `npm run build` ثم `npm run deploy`. في أول نشر يدوي، أضف `SETUP_TOKEN` خاصًا عبر `npx wrangler secret put SETUP_TOKEN`؛ لا تضعه في ملف المصدر. [شرح التثبيت](docs/DISTRIBUTION.md)، [عقد مورد](docs/MOWARID_API.md)، [الأمان](docs/SECURITY.md).
